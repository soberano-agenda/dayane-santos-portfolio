# Portfólio de Dayane Santos

## Soluções Financeiras Contábeis e Tecnológicas

Este repositório apresenta o portfólio público de **Dayane Santos**, Tecnóloga em Gestão Financeira, Bacharela em Ciências Contábeis e estudante de Análise e Desenvolvimento de Sistemas.

O objetivo é demonstrar soluções desenvolvidas para gestão, contabilidade, análise financeira e tributação, preservando a confidencialidade: as telas utilizam dados fictícios e os códigos dos sistemas originais permanecem em repositórios privados.

## Acesso ao portfólio

O site está publicado no GitHub Pages:

https://soberano-agenda.github.io/dayane-santos-portfolio/

## Projetos apresentados

| Projeto | Demonstração |
| --- | --- |
| Soberano Agenda | Agenda de serviços, vendas, custos, estoque, clientes, comissões, estatísticas e controle disciplinar. |
| Diagnóstico Financeiro | Leitura de demonstrações, indicadores, análises horizontal e vertical e relatórios em Excel e PDF. |
| Soberano Análise Financeira | Matriz de 25 abas com BP, DRE, DFC, DVA, DMPL, auditoria, tributação, notas explicativas e cruzamentos contábeis. |
| Soberano Agenda Google | Calendário com visualização semanal e organização de compromissos. |
| Simples Nacional | Enquadramento de MEI, ME e EPP, Fator R, anexos, limites e calendário de obrigações. |
| Planejamento Tributário | Comparação entre Simples Nacional, Lucro Presumido e Lucro Real, com laboratório de BP, DRE e ARE. |
| Soberano ERP | Financeiro, estoque, comercial, fiscal, folha, tributação, contabilidade, auditoria e PWA. |

## Evidências técnicas

Cada projeto no site possui uma página de evidências com o escopo de documentação, regras de negócio, validações, rotinas de teste e entregáveis correspondentes ao respectivo sistema.

## Conteúdo público e seguro

- Dados demonstrativos e fictícios.
- Nenhuma informação de clientes ou empresas reais.
- Nenhum código-fonte dos sistemas privados.
- Repositório dedicado exclusivamente à apresentação profissional.
